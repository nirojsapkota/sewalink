class Admin::BaseController < ApplicationController
  layout 'admin'
  before_action :authenticate_user!
  before_action :ensure_admin!

  private

  def ensure_admin!
    redirect_to root_path, alert: "Access denied. Admin only." unless current_user&.admin_access?
  end

  def require_super_admin!
    redirect_to admin_root_path, alert: "Access denied. Super admin only." unless current_user&.super_admin?
  end

  def log_admin_action!(action, target = nil, details: {})
    AdminActivityLog.record!(admin: current_user, action: action, target: target, details: details)
  end
end

Current app/controllers/admin/users_controller.rb (full file — `change_role` action and its route/before_action reference must be replaced, everything else preserved):
```ruby
class Admin::UsersController < Admin::BaseController
  before_action :set_user, only: [:show, :edit, :update, :suspend, :reactivate, :change_role]
  # ... index, show, edit, update, suspend, reactivate unchanged ...

  def change_role
    if @user == current_user
      redirect_to admin_user_path(@user), alert: "You cannot change your own admin access." and return
    end
    new_admin_value = ActiveModel::Type::Boolean.new.cast(params[:admin])
    previous_admin_value = @user.admin?
    if @user.update(admin: new_admin_value)
      log_admin_action!("change_admin_role", @user, details: { from: previous_admin_value, to: new_admin_value })
      redirect_to admin_user_path(@user), notice: new_admin_value ? "Admin access granted." : "Admin access revoked."
    else
      redirect_to admin_user_path(@user), alert: "Failed to change admin access: #{@user.errors.full_messages.join(', ')}"
    end
  end

  private
  def set_user
    @user = User.find(params[:id])
  end
  def user_params
    params.require(:user).permit(:first_name, :last_name, :bio, :locale, :active_role)
  end
end
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Accountant session → role-management routes | An authenticated accountant (valid admin-capable session) attempting to escalate by directly hitting `PATCH /admin/users/:id/roles` or `GET /admin/roles` without going through the UI (which hides these controls from non-super-admins) |
| Super admin session → own user record | A super admin attempting to modify their own roles, which could lock the platform out of role management if the last super_admin demotes themselves |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|--------------|------------------|
| T-10-05 | Elevation of Privilege | `Admin::UsersController#update_roles` | mitigate | `before_action :require_super_admin!, only: [:update_roles]` enforced at controller level, not just hidden in the view — covered by Test 4 |
| T-10-06 | Elevation of Privilege | `Admin::RolesController#index` | mitigate | `before_action :require_super_admin!` on the whole controller — covered by Test 5 |
| T-10-07 | Denial of Service (self-lockout) | `Admin::UsersController#update_roles` | mitigate | Explicit `@user == current_user` guard blocks a super admin from changing their own roles via this action — covered by Test 3 |
| T-10-08 | Tampering | `params[:roles]` array | mitigate | Requested roles filtered through `& [:super_admin, :accountant]` allow-list before any `add_role` call — prevents assigning arbitrary/unknown role names |
</threat_model>
