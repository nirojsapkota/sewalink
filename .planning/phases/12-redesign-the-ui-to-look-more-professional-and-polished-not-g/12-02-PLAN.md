```ruby
# Buttons: class: button_class(:primary | :secondary | :destructive | :ghost)
def button_class(variant = :primary); end

# Cards: class: card_class or class: card_class(interactive: true) for clickable/navigable cards (e.g. task list items)
def card_class(interactive: false); end

# Form inputs: class: input_class
def input_class; end

# Status badges (unchanged signature, now returns slate/indigo/green/amber/red tokens):
# class: status_badge_class(task.status) -> e.g. "bg-indigo-50 text-indigo-700"
def status_badge_class(status); end

# Nav-style links (unchanged signature):
def nav_link_class(path); end
```

## Color/Class Migration Map (same table as Plan 01 — apply identically here)

| Old pattern | New pattern |
|---|---|
| `#7C3AED` (bg/text/border) | `indigo-600` |
| `#6D28D9` (hover) | `indigo-700` |
| `#4C1D95` full opacity | `slate-900` (headings) or `slate-700` (body/label) |
| `#4C1D95/70` | `slate-600` |
| `#4C1D95/60` | `slate-500` |
| `#4C1D95/40` | `slate-400` |
| `#4C1D95/20` (border) | `slate-200` |
| `#4C1D95/10`, `#4C1D95/5` | `slate-100` |
| `#FAF5FF` | `white` or `slate-50` |
| `#F3E8FF` (chip/badge bg) | `slate-100` (or `indigo-50` if the badge is specifically an "info" pill per UI-SPEC Badges) |
| `#E9D5FF` (chip hover bg) | `slate-200` |
| `#22C55E` (literal hex dot) | `green-500` |
| `font-['Mukta']` | remove (inherits `@theme` font-sans) |
| `hover:-translate-y-*`, `active:translate-y-*`, `hover:scale-*`, `active:scale-*` | remove entirely |
| `backdrop-blur-*`, decorative `blur-3xl` gradient blobs | remove entirely |
| `shadow-lg`/`shadow-xl`/`shadow-2xl` at rest | `shadow-sm` (cards), or remove for buttons |
| `animate-pulse` | remove EXCEPT the voice-recording mic button state in `home/index.html.slim` (functional recording indicator, explicitly allowed to keep pulse per UI-SPEC Motion & Interaction exception) |
| `font-black`/`font-extrabold`/`font-bold` | `font-semibold` (600 max) |
| Ad-hoc button classes (`bg-[#...] text-white px-... rounded...`) | `button_class(:primary\|:secondary\|:destructive\|:ghost)` |
| Ad-hoc card wrapper classes (`border rounded-xl p-5 bg-white hover:shadow-lg`) | `card_class` or `card_class(interactive: true)` |
| Ad-hoc input classes | `input_class` |
| Ad-hoc status/category pill classes | `status_badge_class(status)` where a task/bid status exists; otherwise inline `bg-slate-100 text-slate-700` (neutral) per UI-SPEC Badges section |

## Example transformation (from 12-RESEARCH.md, illustrates the pattern to apply across all files in this plan)

Before (`app/views/tasks/_task_card.html.slim`, current file):
```slim
.border.rounded-xl.p-5.hover:shadow-lg.transition-shadow.bg-white.relative
  .flex.justify-between.items-start.mb-3
    span class="inline-block px-2 py-1 text-xs font-semibold rounded-full bg-[#F3E8FF] text-[#4C1D95]"
      = I18n.locale == :ne ? task.category.name_ne : task.category.name_en
    ...
  = link_to t('.bid_now', default: 'Details & Bid'), task, class: "block text-center rounded-lg py-2 px-4 bg-[#7C3AED] text-white font-medium hover:bg-[#6D28D9] transition-colors"
```

After:
```slim
div class="#{card_class(interactive: true)} relative"
  .flex.justify-between.items-start.mb-3
    span class="inline-block px-2 py-1 text-xs font-semibold rounded-full bg-slate-100 text-slate-700"
      = I18n.locale == :ne ? task.category.name_ne : task.category.name_en
    ...
  = link_to t('.bid_now', default: 'Details & Bid'), task, class: "block text-center #{button_class(:primary)}"
```
Apply this same "replace hardcoded hex/shadow with `card_class`/`button_class`/`status_badge_class`/`input_class` helper calls, replace remaining hex per the migration map" approach to every file listed in this plan's `files_modified`.
