# SewaLink Platform Overview

*Knowledge Base Factsheet · General audience · Version 1.0*

## What is SewaLink?

SewaLink is a mobile-first marketplace that connects task "posters" (people who need help) with local service "taskers" (people who get paid to do the work) across Nepal. Posters describe a job, taskers bid on it, and payment moves through a secure escrow system powered by eSewa, Nepal's leading digital wallet and payment gateway.


## Who uses SewaLink?

- Posters — individuals or businesses who need a task done (cleaning, repairs, moving, tutoring, errands, event help, and more).
- Taskers — verified individuals who browse open tasks, submit bids, and complete work for pay.
- Admins — SewaLink staff who moderate tasks, review disputes, manage payouts, and configure platform-wide settings.


## Core idea in one sentence

Post a task → review bids → hire a tasker → track progress in real time → pay safely through escrow → rate each other.


## Supported languages

SewaLink is bilingual. Every screen, notification, and category name is available in English and Nepali (नेपाली), so users can switch language from their profile settings at any time.


## Where it runs

SewaLink is a web app built with Ruby on Rails and Hotwire, so it works directly in a mobile browser without needing to install a native app, while still feeling fast and app-like.
