# Task Lifecycle & Status Reference

*Knowledge Base Factsheet · For Posters & Taskers · Version 1.0*

## Overview

Every task on SewaLink moves through a fixed set of statuses. Understanding these helps you know what action (if any) is expected of you at each stage.


## Status reference

| Status | What it means | Who acts next |
| --- | --- | --- |
| Draft | Task saved but not yet published | Poster publishes it |
| Open | Visible to taskers; accepting bids | Taskers submit bids |
| Assigned | A bid has been accepted | Tasker starts work |
| In Progress | Tasker is actively working | Tasker completes it |
| Pending Payment | Marked complete; awaiting poster confirmation | Poster confirms |
| Payment Completed | Escrow released to tasker | Both leave a review |
| Completed | Task fully closed | None — archived |
| Dispute | A disagreement was raised | Admin reviews and resolves |
| Cancelled | Task called off before completion | None — archived |


## Guardrails built into the system

- A task cannot be started or completed from outside the allowed geofence when on-site check-in is required.
- A completion photo is required before an on-site task can be marked complete.
- Escrow funds are only released automatically after the poster confirms completion, or after an admin resolves a dispute in the tasker's favor.


## Raising a dispute

Either party can raise a dispute if something goes wrong (no-show, incomplete work, payment disagreement). This pauses the automatic escrow release and routes the task to SewaLink admins for manual review.
